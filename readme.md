# 介绍

**哔哩终端**是一个**轻量级**的第三方 B 站客户端，为**小屏 / 手表**场景做了大量适配（圆屏安全区、表冠操作、单手可达的控件布局），同时也能在手机上正常使用。

- 名字来源于原神中的「虚空终端」；本项目 Fork 自 [RobinNotBad/BiliClient](https://gitee.com/RobinNotBad/BiliClient)，核心功能与架构出自原作者。
- 本仓库是**个人维护的修改版**：在原作者成果之上做修复、重构与新功能，主要面向作者自己的手表使用场景。
- 源码已全部迁移到 **Kotlin**（`app/src/main/java` 下 0 个 Java 文件）。

## 主要功能

- **视频**：推荐、热门、排行榜、入站必刷、搜索、UP 主投稿 / 合集、稍后再看、收藏、历史、下载
- **播放器**（内置）：弹幕（protobuf 分段拉取 + 缺失段补拉）、清晰度切换、倍速（长按 2.0x / 菜单 0.5~3.0x）、字幕、进度拖动与输入跳转、弹幕时间戳跳转、卡死看门狗自动恢复、WiFi 预加载
- **直播**：推荐 / 关注直播、弹幕 WebSocket 与断线重连
- **动态、消息、评论、私信、专栏、番剧**
- **移动端推荐逻辑（实验）**：推荐页可切换为 APP 端接口，客户端身份支持 **HD / TV / 手机** 三端各自独立扫码登录，互不影响，也不影响软件本身的 Web 登录
- **短视频（实验）**：竖屏专用流（`/x/v2/feed/index/story`），上滑下一个 / 下滑上一个 / 表冠切换，自动连播，支持弹幕、倍速、清晰度、画面比例
- **手表适配**：圆屏安全区、表冠滚动、双击暂停、单击显隐控制层
- **其他**：主题色调、双列信息流、消息设置、收藏夹多选缓存、断点续传下载

## 系统要求

- **Android 10（API 29）及以上**；`targetSdk 30`、`compileSdk 33`
- **32 位（armeabi-v7a）**：APK 内只打包了 `armeabi-v7a` 原生库，**纯 64 位系统（不支持 32 位应用的设备）无法安装**
- 手表需能安装第三方 APK；圆屏设备建议在「设置 → 界面」中开启**圆屏适配**

## 下载与安装

- 所有版本都在 [Gitee Releases](https://gitee.com/yykkxxykx/BiliClient/releases) 发布，**预发布版（alpha/beta）也只在 Gitee**。
- 安装包分两种：
  - **主包**：包名 `com.RobinNotBad.BiliClient`，正常安装即可；
  - **渠道包**（`com.tencent.qqmusicwatchs`，应用名「QQ音乐」）：部分设备出于兼容性或规避检测需要时使用；其中 `*_hidden.apk` **没有启动器入口**（桌面不显示图标），需要借助其他方式启动。
- `*_sign.apk` 是使用**正式证书**重签的渠道包（与调试证书版本内容一致，仅签名不同）。**同一台设备上不同证书的包不能互相覆盖安装**，切换前请先卸载。
- 卸载会清空本地数据（登录态、设置、缓存），升级前请注意。

## 版本号规则

- `versionCode` = **构建当天的日期**，格式 `YYYYMMDD`（例如 2026-10-24 构建 → `20261024`），**不是递增序号**。
- `versionName` 采用语义化版本 + 阶段后缀，如 `5.0.2-alpha6`、`5.0.1`。
- 因此**同一天构建的多个版本 versionCode 相同**，可以直接覆盖安装；跨天升级时若新版本日期更早则需先卸载。
- 渠道包的 `versionCode` 固定为 `20260606`、应用名固定为「QQ音乐」（这是渠道包的特殊要求，与主包规则不同）。

# 开发

## 构建要求

| 项 | 版本 |
| --- | --- |
| JDK | 17（Gradle 7.4 不支持更高版本） |
| Gradle / AGP | 7.4 / 7.3.1 |
| Kotlin | 1.7.20 |
| compileSdk / targetSdk / minSdk | 33 / 30 / 29 |
| ABI | `armeabi-v7a` |

```bash
# 编译（终端环境注意先配好 JDK17 / Android SDK / Gradle 缓存）
./gradlew :app:compileDebugKotlin
# 出包
./gradlew :app:assembleRelease
```

- 本仓库的 `releases/` 目录按版本分子目录存放构建产物（`releases/<versionName>/`），每个目录内有 `SHA256SUMS.txt`。
- 特殊渠道包由 `changed/build_flavor.sh` 产出，**完全不影响主线代码与构建**，详见 `changed/README.md`。
- 默认签名使用调试证书；正式发布需要自行配置签名。

## 已知限制

- **仅 32 位库**：64 位专用设备无法安装。
- **短视频为实验功能**：依赖的非公开接口随时可能变动或失效。
- **移动端推荐逻辑为实验功能**：三端扫码登录与 APP 端接口均可能被风控或失效。
- 部分功能（弹幕、字幕、互动视频等）在短视频页**未提供**，短视频页只保留常用播放能力。
